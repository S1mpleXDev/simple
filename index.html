Demo Texture Maker

This v1.0 editor is a local static pixel-art workspace. The UV guide is generated by the editor itself; it does not ship with or embed a user-provided Minecraft texture.

Draw
Pencil, brush, eraser, fill, picker, line, rectangle, ellipse and polygon all show a thin live preview while dragging.
Image kit
Imported images auto-fit inside the texture, preserve aspect ratio, and can be dragged/resized/rotated with touch or mouse.
3D
The preview is WebGL and updates from the current texture. Drag to orbit, wheel/pinch to zoom, and use pose controls.
UV guide
The guide is a clean generated layout based on Bedrock cuboid regions, so no reference image is bundled.
Export
The resource pack writes the texture to Minecraft's wolf texture path: textures/entity/wolf/wolf.png.
Mobile
Use the menu button for tools, the preview button for the 3D panel, and drag directly on the canvas with touch.
